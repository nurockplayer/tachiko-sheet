## Install
These downloads aren't signed yet, so your computer warns you the first time. Check a download against `SHA256SUMS.txt` if you want to be sure it's intact.

**macOS 13 or later (Apple Silicon or Intel):** open the DMG and drag Tachiko Sheet to Applications. Try to open it once, then go to System Settings > Privacy & Security and choose Open Anyway. With Homebrew: `brew install --cask nurockplayer/tap/tachiko-sheet`.

**Windows 10 or 11 (x64):** run the installer. When SmartScreen says it protected your PC, choose More info, then Run anyway.

**Linux (x64):** install the deb with `sudo apt install ./Tachiko-Sheet-*.deb` (Ubuntu 22.04 or later). Or make the AppImage executable with `chmod +x` and run it; the AppImage needs FUSE 2, which Ubuntu leaves out by default: `sudo apt install libfuse2t64` on 24.04, `sudo apt install libfuse2` on 22.04.
